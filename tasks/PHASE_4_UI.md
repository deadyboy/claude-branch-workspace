# Phase 4 — Usable UI

## Objective

完成用户真正可以工作的三栏 UI。

## Minimum

左：
Conversation Tree

中：
Persistent Branch Chat

右：
Agent/Execution Monitor

底部或可切换：
Timeline/Attention

## Critical interactions

- click branch
- send message
- fork from specific turn
- rename branch
- archive branch
- interrupt
- see workspace mode
- respond to attention/permission
- inspect agent/tool activity

## Explicit non-priority

“小人动画”不是 Gate。

先完成状态卡/列表；动画作为 enhancement。

## Gate

用户不打开 terminal，也能完成：
Main -> 历史 fork -> 子分支对话 -> 子分支再 fork -> 回 Main -> 继续对话。
